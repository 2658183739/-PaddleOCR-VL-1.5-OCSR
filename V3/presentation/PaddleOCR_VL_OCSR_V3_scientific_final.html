05 · 密封卷

为什么不是 1:1:1:1:1:1:1

科学配比的目标不是“平均”，而是同时控制遗忘、弱域暴露和数据吞噬

43.55%

保护基础能力

  • UOB + USPTO 是 printed 锚点
  • 避免弱域过采样后忘掉基本 OCSR
  • repeat 1，保留原始分布
19.02%

把稀缺弱域放大到可学习

  • 真实场景错误率高、数量少
  • 历史策略 repeat 5
  • 强调拍照、扫描、手写与页面
≤1,513

限制干净数据支配训练

  • 三个 USPTO-30K 子集分别 cap
  • MolGrapher repeat 2，但不算真实评测
  • 防止模型被规整专利图拉回去
统计边界：比例由 V2-1 错误分层、标签可信度和 2×2 探索共同约束；只有两个 seed，不能声称全局最优。

15 / 18

一个数字不能回答所有问题

Exact、Valid、相似度和 scaffold 分别回答“对不对、能不能用、错多远、会不会外推”

指标回答的问题不能替代什么V3 用法
Canonical exact结构是否完全正确？不能由 valid / Tanimoto 替代主指标
Valid SMILESRDKit 能否解析？语法合法不等于结构正确采用闸门
Token F1 / Tanimoto错误离真值多远？不能当完全命中错误诊断
Scaffold-novel exact未见骨架能否泛化？不能代表全部真实域locked 诊断
Paired cluster CI净变化是否稳定？不能替代训练 seed 不确定性beam 对照
图像 N ≠ 独立 N
同一结构多视角按 structure_id 聚类；论文图按 paper_group 聚类。
development ≠ unseen
42.07% 是选 decoder 的模拟题；22.92% 才是 locked 论文图结果。
